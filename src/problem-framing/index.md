# Problem Framing, Ethics & Judgment

**Mission.** Turn business questions into data questions, and know when not to use ML.

## Scope

- Problem framing and metric design
- Tradeoff analysis and the cost of being wrong
- Bias and fairness
- Privacy and responsible AI
- Build vs. buy, and the boring solution

## Learning objectives

- Turn a vague stakeholder request into a testable, scoped data question
- Name the failure modes of a proposed model before it ships
- Argue for the boring solution when the boring solution wins
